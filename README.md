# chitai-gorod

Автоматизированные UI- и API-тесты из финальной работы по ручному тестированию "Тестирование интернет
магазина книг “Читай- город”."

## Ссылка на финальный проект по тестированию
"https://skypro6.yonote.ru/share/d703f495-ef43-4dc3-9209-34a124cb6117"

## Описание проекта
Данный проект содержит набор автоматизированных тестов для интернет-магазина книг "Читай-город".
Тесты охватывают как функциональность API, так и пользовательский интерфейс (UI), обеспечивая надежное 
тестирование различных операций, таких как добавление и удаление из корзины, а так же тестирование
функционального поиска.

## Структура проекта

- pages/ - пакет с классами
- pages/add_to_cart_ui.py - добавление товара в корзину
- pages/delete_from_cart_ui.py - удаление товара из корзины
- pages/search_by_author_ui.py -поиск по автору
- pages/search_by_latina_ui.py - поиск по латинице
- pages/search_by_title_ui.py - поиск по названию
- pages/api_client.py - клиент для API тестов
- test - пакет с тестами
- test/test_ui.py - UI тесты
- test/test_api.py - API тесты
- conf.py - конфигурационные переменные (URL, токены)
- conftest.py - фикстуры pytest
- pytest.ini - конфигурация pytest (маркеры, пути)
- requirements.txt - зависимости проекта

## Технологии
1. Python
2. Requests (для выполнения API-запросов)
3. Allure (для тестирования и отчетности)

## Установка
1. Клонируйте репозиторий: git clone [https://github.com/boarovaolga/chitai-gorod.git]
2. Перейдите в каталог проекта Chitai-gorod
3. Настройте переменные окружения. Перед запуском приложения убедитесь, что у вас 
установлены необходимые переменные окружения.

## Получение токена
Для работы с API вам понадобятся токен. 
1. Заходим в devtools на сайте читай-город
2. Переходим во вкладку application
3. Находим cookies читай город 
4. Находим access token, копируем в conf.py
Не забываем обновлять токен час.

## Запуск тестов API
pytest -m api -v --alluredir=allure-results - если с отчетом
pytest -m api - без отчета

## Запуск тестов UI
pytest -m ui -v --alluredir=allure-results - с отчетом
pytest -m ui - без отчета

## Запуск всех тестов
pytest -v --alluredir=allure-results - с отчетом
pytest - без отчета
